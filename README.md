# Job Application & Interview Tracker

## Overview

The Job Application & Interview Tracker is a full-stack web application designed to help job seekers manage applications submitted through multiple job portals from one centralized location.

## Problem Statement

Job seekers often apply through different platforms such as LinkedIn, Naukri, and Hirist. Tracking saved jobs, application statuses, job details, and interviews across these platforms can become difficult.

This application aims to simplify the process by providing a searchable and organized dashboard for managing job applications.

## MVP Features

* Add, view, edit, and delete job applications.
* Record the company, original job title, standardized job type, job portal, job URL, and job ID.
* Track application statuses such as Saved, Applied, Assessment, Interview, Offer, Rejected, and Withdrawn.
* Search applications by company, job title, or job ID.
* Filter applications by portal, status, dates, standardized job type, and skills.
* Maintain a history of application status changes.
* Record interview dates, rounds, and notes.
